# Security Policy

## Reporting a Vulnerability

The Mermail Digital Inheritance Switch (MDIS) team takes security and fund safety seriously. If you discover a vulnerability, please report it responsibly.

### Contacts
- **Security Email:** security@mermail.io
- **Emergency Channel:** Report via private disclosure repository or designated security contacts.

### Scope
- On-chain Solana Program: `programs/mermail-deadman-vault` (`E4dA4YrWnMgFv7NNseHjw8r2yikArPGiEnrxX4YYExdX`)
- Off-chain Cloudflare Workers & Notification Orchestrator: `worker.mjs`, `telegram-notifier.mjs`, `shamir.mjs`

### Responsible Disclosure Guidelines
- Give the team reasonable time to investigate and mitigate the issue before public disclosure.
- Do not attempt to access or drain user funds on Mainnet or public networks.
- Provide detailed reproduction steps or Proof of Concept (PoC).
